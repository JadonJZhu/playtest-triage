Playtest Triage

Proof-of-concept: use an LLM to categorize playtest comments into themes for easier downstream processing.

All comments are about an invented game called Hollowgate.

How this works

What is being tested: can an LLM sort playtest comments into the same themes a person would? 120 comments about Hollowgate were written with 8 themes planted in them and labelled by hand. The prompt was tuned on 40 and then tested on the other 80. Deterministic code was then used to verify every quote the model provides.

Scoring looks at every pair of comments: did the model and the ground truth labels agree that they belong together? Precision is how often the model's pairs are correct, recall is how many of the correct pairs it actually found, and F1 is the harmonic mean of those two measurements. The baseline comparison groups comments by shared words, with no LLM.

In this test, the LLM model we use is deepseek-v4.1-flash.
